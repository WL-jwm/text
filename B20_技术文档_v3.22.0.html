1 项目概述

1.1 平台定位

河北省地下水环境信息平台是一款基于Web的地下水专业技术数据库与知识平台，面向河北省地下水环境影响评价、水文地质调查、碳核查等环保技术咨询服务场景，提供系统化的地下水基础数据检索、可视化分析与辅助决策支持。

1.2 核心能力

能力域说明
水文地质基础资料地质构造、第四纪地层、含水层组划分、水文地质参数、系统分区等
地下水资源评价平原区水资源平衡、各市开采量、补给模数、可开采量评价
地下水环境质量水质监测、地下水质量标准、污染程度评价、水化学分区
地下水超采与治理浅/深层漏斗分布、超采区划定、水位恢复、取水许可管理
特种地下水岩溶水、裂隙水、地热水、矿泉水、咸水
矿山水文地质矿床充水条件、突水案例、矿井排水影响评价
环境地质土壤盐渍化、咸水分布与利用、地下水功能区划
高级可视化水文地质剖面图、含水层三维结构、等值线图、动态时间轴

2.3 数据层设计

数据层采用纯静态TypeScript模块，所有数据以类型化常量形式内嵌于.ts文件中，无需后端API。数据模块通过命名导出暴露各主题数据集，页面组件按需导入。

搜索机制：全局搜索基于searchIndex.ts预构建的倒排索引（kw()函数），搜索覆盖所有数据模块的中文关键词、拼音首字母缩写和英文术语。

持久化：个人工作台使用IndexedDB实现浏览器端持久化存储，支持数据导入、标注笔记和收藏快照的跨会话保留。

7.3 Nginx配置

server {
    listen 80;
    server_name your-domain.com;

    root /path/to/frontend/dist;
    index index.html;

    # SPA路由回退
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 静态资源缓存（Vite使用内容哈希文件名，可设长缓存）
    location /assets/ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # Service Worker不缓存
    location /sw.js {
        add_header Cache-Control "no-cache, no-store, must-revalidate";
        expires off;
    }

    # precache-manifest不缓存
    location /precache-manifest.json {
        add_header Cache-Control "no-cache, no-store, must-revalidate";
        expires off;
    }

    # Gzip压缩
    gzip on;
    gzip_types text/css application/javascript application/json image/svg+xml;
    gzip_min_length 1024;
}

7.4 PWA离线缓存策略

平台的PWA实现基于手动编写的Service Worker（sw.js，4.1KB），采用分层缓存策略：

策略适用资源说明
Pre-cache（预缓存）全部44个构建资产SW安装时缓存所有静态文件，总计约2MB
Stale-While-RevalidateCSS/JS/字体/图片优先返回缓存，后台更新缓存供下次使用
Network FirstHTML导航请求优先网络请求，失败时回退缓存
版本更新机制：每次构建后自动生成precache-manifest.json，SW激活时对比清单，自动清理过期缓存。版本号变更触发SW更新提示。

7.5 部署检查清单

  1. 构建产物完整性：确认dist/包含index.html + assets/ + sw.js + manifest.json + precache-manifest.json
  2. SPA路由配置：确认Nginx try_files配置正确，所有路由返回index.html
  3. HTTPS启用：PWA Service Worker在HTTP环境下不可用
  4. Service Worker注册：打开浏览器DevTools → Application → Service Workers确认已注册
  5. 离线测试：DevTools Network面板切换Offline模式，刷新页面确认离线可用
