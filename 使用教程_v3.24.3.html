1 平台简介

河北省地下水环境信息平台是一款面向环保技术咨询领域的专业Web应用，由河北瑞三元环境科技有限公司技术团队开发。平台聚焦河北省地下水环境影响评价、水文地质调查与碳核查等业务场景，系统整合了河北省全境水文地质基础数据，提供数据检索、可视化分析与辅助决策支持。

核心能力：

  • 水文地质基础资料：地质构造、第四纪地层、含水层组划分、水文地质参数
  • 地下水资源评价：平原区水资源平衡、各市开采量、补给模数、可开采量评价
  • 地下水环境质量：水质监测、地下水质量标准、污染程度评价、水化学分区
  • 地下水超采与治理：浅/深层漏斗分布、超采区划定、水位恢复、取水许可管理
  • 特种地下水：岩溶水、裂隙水、地热水、矿泉水、咸水
  • 矿山水文地质：矿床充水条件、突水案例、矿井排水影响评价
  • 环境地质：土壤盐渍化、咸水分布与利用、地下水功能区划
  • 高级可视化：水文地质剖面图、含水层三维结构、等值线图、动态时间轴

6 高级可视化组件

6.1 水文地质剖面图（HydroProfile）

位置： 地质构造页面（/geology）→ "地层剖面"Tab

SVG绘制的河北平原典型水文地质剖面图，展示山前冲洪积带 → 中部冲积湖积带 → 滨海海积带三带剖面，深度范围0~600m。鼠标悬停在岩性区域上可查看岩性详情。

6.2 含水层三维结构（Aquifer3D）

位置： 地质构造页面（/geology）→ "含水层组"Tab

CSS 3D Transform实现的含水层三维结构示意。支持鼠标拖拽旋转查看各层关系，点击各层可查看参数信息。

6.3 等值线图（ContourMap）

位置： 地下水环境页面（/environment）→ "浅层漏斗"/"深层漏斗"Tab

Canvas 2D绘制的等值线/等值面填充图，基于IDW插值和Marching Squares算法生成。鼠标悬停显示坐标和插值。用于展示浅层和深层地下水漏斗分布。

6.4 动态时间轴（TimeAxis）

位置： 开采管理页面（/exploitation）→ "趋势演变"/"治理里程碑"Tab

Canvas 2D动画驱动的时间轴可视化，展示河北省地下水开采量演变趋势和治理里程碑。支持播放/暂停、速度调节、进度条拖拽跳转。

8 打印与离线使用

8.1 打印适配

平台已针对环评报告附录打印场景优化：

  • A4页面尺寸，15mm边距
  • 白底深色文字，隐藏交互元素（按钮、搜索框、导航栏等）
  • 表格避免跨页断行
  • 图表容器避免跨页
  • 数据来源标注保留在打印输出中

使用浏览器"打印"功能（Ctrl+P）即可输出。

8.2 PWA离线缓存

平台支持PWA离线缓存，首次访问后所有静态资源（约2MB）自动缓存到本地。离线状态下仍可正常浏览已缓存的页面和数据。

启用条件： 通过 http://localhost:3000 访问（非 file:// 协议），浏览器支持Service Worker。

8.3 版本更新提示

平台版本更新后，Service Worker会自动检测新版本并提示用户刷新页面加载最新内容。每次构建后precache-manifest.json自动更新，SW激活时清理过期缓存。

9 常见问题

9.1 启动后浏览器显示空白

原因： 使用 file:// 协议直接打开 index.html 时，浏览器安全策略禁止加载ES Module。

解决： 必须通过本地服务器访问。使用桌面快捷方式启动，或手动执行 python -m http.server 3000 后访问 http://localhost:3000。

9.2 数据是否实时更新

平台数据为静态内嵌数据，更新频率取决于数据来源（水资源公报为年度更新，地质志为固定型）。更新需重新构建部署。

9.3 如何判断数据可靠度

每个数据模块在"数据源注册表"（/changelog）中标注了可靠度（高/中/低）。高可靠度数据来自官方公报和国标，中可靠度来自文献和历史资料。

9.4 离线时部分功能不可用

PWA离线缓存确保页面浏览和数据查看正常，但数据导入/导出等需要浏览器API支持的功能可能受限。

9.5 如何反馈问题或建议

可通过以下方式反馈：

9.6 如何将数据引用到环评报告

推荐工作流：

  1. 在平台中查找所需数据
  2. 点击TechCard右上角"导出数据"按钮，选择XLSX格式导出
  3. 将导出的Excel数据表直接粘贴或引用到Word报告中
  4. 如需截图图表，使用浏览器打印功能（Ctrl+P）输出为PDF
