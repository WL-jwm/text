# 水质评价计算器使用说明

> 河北省地下水环境信息平台 — 水质评价计算器 v1.0
>
> 功能位置：水质评价页面 → 评价计算 Tab

## 1 功能概述

水质评价计算器是基于 **GB/T 14848-2017《地下水质量标准》** 的在线计算工具，提供两大核心功能：

| 模块 | 功能 | 适用场景 |
|------|------|---------|
| 标准指数法 | 单因子标准指数法评价，综合评定水质类别 | 环评报告中地下水水质现状评价、监测数据批量评价 |
| 苏卡列夫分类 | 水化学类型分类，输出舒卡列夫分区号 | 地下水化学成分分析、水化学图编制、水文地质条件描述 |

### 计算引擎

- **标准指数法**：对每个评价因子计算标准指数 Pi，以最差类别作为综合评定结果
- **苏卡列夫分类**：将6种主要离子浓度换算为毫当量浓度（meq/L），计算毫克当量百分比（%ep），按 >25%ep 的离子组合确定水化学类型和分区号

## 2 标准指数法

### 2.1 基本原理

根据 GB/T 14848-2017，采用 **单因子标准指数法** 对地下水质量进行评价：

- 对每个评价因子，分别计算其在 I~V 类标准中的所属类别
- **综合评定**：取所有参评因子中的 **最差类别** 作为该水样的水质类别

> 单因子评价法的特点是"一票否决"——只要有一个因子超标，整个水样的综合评定结果即为该因子的最差类别。

### 2.2 标准指数 Pi 计算

#### 一般因子

$$P_i = \frac{C_i}{S_i}$$

其中：
- $C_i$ — 第 $i$ 个评价因子的监测浓度值（mg/L）
- $S_i$ — 第 $i$ 个评价因子的标准限值（取 III 类标准上限值）

Pi 的含义：
- Pi ≤ 1.0 → 达到 III 类标准
- Pi > 1.0 → 超过 III 类标准，值越大超标越严重

#### pH 的特殊处理

pH 不采用上述通用公式，而是按以下方式计算：

$$P_{pH} = \frac{7.0 - pH_i}{7.0 - pH_{sd}} \quad (pH_i < 7.0)$$

$$P_{pH} = \frac{pH_i - 7.0}{pH_{su} - 7.0} \quad (pH_i > 8.5)$$

$$P_{pH} = 0 \quad (6.5 \leq pH_i \leq 8.5)$$

其中：
- $pH_i$ — 监测 pH 值
- $pH_{sd}$ — III 类标准下限值 = 6.5
- $pH_{su}$ — III 类标准上限值 = 8.5

pH 类别判定：
| pH 范围 | 类别 |
|---------|------|
| 6.5 ~ 8.5 | I 类 |
| < 6.5 | IV 类 |
| < 5.5 | V 类 |
| > 8.5 | IV 类 |
| > 9.0 | V 类 |

### 2.3 未检出数据处理

当监测结果为"未检出"时，按以下规则处理：

- 以 **检出限的 50%** 参与计算
- Pi 值极小（通常 < 1%），自动评定为 I 类
- 结果表中监测值列显示为"未检出 <检出限"，保留原始信息

**输入格式**：在监测值输入框中直接输入含"未检出"的文本即可自动识别，支持以下格式：

| 输入示例 | 识别结果 |
|---------|---------|
| `未检出0.01` | 未检出，检出限 0.01，以 0.005 参与计算 |
| `未检出 <0.05` | 未检出，检出限 0.05，以 0.025 参与计算 |
| `未检出(0.02)` | 未检出，检出限 0.02，以 0.01 参与计算 |

## 3 苏卡列夫水化学分类

### 3.1 基本原理

苏卡列夫分类法（Сукачёв）是一种基于地下水主要化学成分的分类方法，广泛用于水文地质调查和环评报告中描述地下水化学特征。

核心思路：
1. 将 6 种主要离子的质量浓度（mg/L）换算为 **毫当量浓度**（meq/L）
2. 分别计算阴离子和阳离子的 **毫克当量百分比**（%ep）
3. 取 **>25%ep** 的离子纳入水化学类型命名
4. 根据阴/阳离子优势组合确定 **苏卡列夫分区号**

### 3.2 毫当量浓度计算

$$meq/L = \frac{C \times z}{M}$$

其中：
- $C$ — 离子浓度（mg/L）
- $z$ — 离子化合价
- $M$ — 离子摩尔质量（g/mol）

各离子参数：

| 离子 | 化学式 | 摩尔质量 (g/mol) | 化合价 |
|------|-------|-----------------|--------|
| 重碳酸根 | HCO₃⁻ | 61.017 | 1 |
| 硫酸根 | SO₄²⁻ | 96.06 | 2 |
| 氯离子 | Cl⁻ | 35.453 | 1 |
| 钙 | Ca²⁺ | 40.078 | 2 |
| 镁 | Mg²⁺ | 24.305 | 2 |
| 钠 | Na⁺ | 22.990 | 1 |

### 3.3 百分当量计算

$$\%ep(\text{阴离子}) = \frac{meq_i}{\sum meq(\text{阴离子})} \times 100$$

$$\%ep(\text{阳离子}) = \frac{meq_i}{\sum meq(\text{阳离子})} \times 100$$

### 3.4 水化学类型命名规则

**命名格式**：`阴离子优势 - 阳离子优势`

- 将 >25%ep 的离子按含量从高到低排列，用中间点（·）连接
- 示例：HCO₃ 的 %ep = 65%，SO₄ 的 %ep = 20%，Cl 的 %ep = 15% → 阴离子优势为 HCO₃；Ca 的 %ep = 55%，Mg 的 %ep = 30%，Na 的 %ep = 15% → 阳离子优势为 Ca·Mg → 水化学类型为 **HCO₃-Ca·Mg**

### 3.5 苏卡列夫分区号

分区号范围 1~49，由阴离子行序号和阳离子列序号确定：

| 行 | 阴离子组合 | 列 | 阳离子组合 |
|----|-----------|----|-----------|
| 1 | HCO₃ | 1 | Ca |
| 2 | SO₄ | 2 | Mg |
| 3 | Cl | 3 | Na |
| 4 | SO₄·Cl | 4 | Ca·Mg |
| 5 | HCO₃·SO₄ | 5 | Ca·Na |
| 6 | HCO₃·Cl | 6 | Mg·Na |
| 7 | HCO₃·SO₄·Cl | 7 | Ca·Mg·Na |

分区号 = (行 - 1) × 7 + 列。例如 HCO₃-Ca → 行1列1 → 分区号 **1**；HCO₃-Ca·Mg → 行1列4 → 分区号 **4**。

## 4 操作步骤

### 4.1 进入计算器

1. 在平台侧边栏点击 **"水质评价"** 进入水质评价页面
2. 在页面顶部 Tab 栏中，点击 **"评价计算"** Tab（带计算器图标）

### 4.2 标准指数法操作

#### 步骤 1：输入水样数据

默认提供一个空水样卡片"水样1"，表格中已预填全部 16 个评价因子及对应的 III 类标准限值。在每个因子的 **"监测值"** 列输入实际监测数据：

- **数值型数据**：直接输入数字，如 `0.05`、`250`、`7.2`
- **未检出数据**：输入含"未检出"的文本，如 `未检出0.01`、`未检出 <0.05`
- **pH 值**：输入小数，如 `7.2`、`6.8`

> 提示：无需填写所有因子。未填写的因子将自动跳过，不影响其他因子的计算。

#### 步骤 2：管理多个水样

- 点击 **"添加水样"** 按钮新增一个空水样卡片
- 点击水样卡片右上角的 **垃圾桶图标** 删除该水样（至少保留 1 个）
- 点击水样名称可直接编辑水样名称（如改为井号"GW-01"）

#### 步骤 3：执行计算

点击 **"计算评价"** 按钮，系统将：
1. 逐一解析每个水样中已填写的监测值
2. 对每个有效因子计算标准指数 Pi 和评定类别
3. 取最差类别作为综合评定结果
4. 输出评价结果面板

#### 步骤 4：查看结果

计算结果分为两部分：

**综合评定概览**：以卡片形式展示每个水样的综合水质类别和超标情况：
- 绿色边框 → 全部达标（综合评定 I~III 类）
- 红色边框 → 存在超标因子（综合评定 IV 或 V 类）
- 标注超标因子名称和数量

**标准指数明细表**：列出每个水样各因子的详细计算结果：

| 列 | 内容 |
|----|------|
| 因子 | 评价因子名称 |
| 单位 | 因子单位 |
| 监测值 | 输入的原始值（未检出显示"未检出 <检出限"） |
| S(III类) | III 类标准限值 |
| Pi | 标准指数值 |
| 类别 | 该因子评定类别（I~V 类，颜色区分） |

> 超标因子行以红色背景高亮，便于快速定位问题因子。

### 4.3 苏卡列夫分类操作

#### 步骤 1：切换到苏卡列夫面板

点击面板顶部的 **"苏卡列夫分类"** 按钮，切换到分类输入界面。

#### 步骤 2：输入离子浓度

在 6 个输入框中分别填入对应离子的质量浓度（mg/L）：

| 输入项 | 对应离子 | 说明 |
|-------|---------|------|
| HCO₃⁻ | 重碳酸根 | 阴离子，通常为地下水中优势阴离子 |
| SO₄²⁻ | 硫酸根 | 阴离子 |
| Cl⁻ | 氯离子 | 阴离子 |
| Ca²⁺ | 钙 | 阳离子 |
| Mg²⁺ | 镁 | 阳离子 |
| Na⁺ | 钠 | 阳离子 |

#### 步骤 3：执行计算

点击 **"计算分类"** 按钮，系统输出：

1. **水化学类型**：如 "HCO₃-Ca·Mg"
2. **分区号**：苏卡列夫分区编号（1~49）
3. **阴离子 %ep**：带可视化进度条的各阴离子百分当量
4. **阳离子 %ep**：带可视化进度条的各阳离子百分当量
5. **优势离子排序**：列出超过 25%ep 阈值的离子

> 进度条颜色区分：蓝色/琥珀色表示超过 25%ep 阈值的优势离子，灰色表示低于阈值的离子。

## 5 计算示例

### 示例 1：标准指数法

某监测井 GW-01 的水质监测数据如下：

| 评价因子 | 监测值 |
|---------|--------|
| pH | 7.3 |
| 总硬度(CaCO₃) | 385 mg/L |
| 溶解性总固体(TDS) | 680 mg/L |
| 硫酸盐(SO₄²⁻) | 120 mg/L |
| 氯化物(Cl⁻) | 85 mg/L |
| 铁(Fe) | 未检出0.05 mg/L |
| 锰(Mn) | 0.08 mg/L |
| 高锰酸盐指数 | 2.5 mg/L |
| 氨氮(NH₃-N) | 0.15 mg/L |
| 氟化物(F⁻) | 0.8 mg/L |
| 硝酸盐(NO₃⁻-N) | 8.5 mg/L |
| 亚硝酸盐(NO₂⁻-N) | 0.02 mg/L |
| 砷(As) | 未检出0.001 mg/L |
| 铬(Cr⁶⁺) | 0.01 mg/L |
| 铅(Pb) | 未检出0.005 mg/L |
| 镉(Cd) | 0.002 mg/L |

**预期结果**：
- pH = 7.3 → I 类（6.5~8.5 范围内，Pi = 0）
- 总硬度 385 mg/L → III 类（≤450，Pi = 0.86）
- 锰 0.08 mg/L → III 类（≤0.10，Pi = 0.80）
- 镉 0.002 mg/L → IV 类（>0.005 III 类限值，Pi = 0.40 但类别为 IV）
- 其余因子均 ≤ III 类
- **综合评定：IV 类**（由镉决定）

### 示例 2：苏卡列夫分类

某水样的离子分析结果：

| 离子 | 浓度 (mg/L) |
|------|------------|
| HCO₃⁻ | 245.0 |
| SO₄²⁻ | 48.0 |
| Cl⁻ | 32.0 |
| Ca²⁺ | 78.0 |
| Mg²⁺ | 35.0 |
| Na⁺ | 18.0 |

**预期结果**：
- HCO₃⁻ meq = 245.0 / 61.017 × 1 = 4.015 meq/L（%ep ≈ 78%）
- SO₄²⁻ meq = 48.0 / 96.06 × 2 = 0.999 meq/L（%ep ≈ 19.5%）
- Cl⁻ meq = 32.0 / 35.453 × 1 = 0.903 meq/L（%ep ≈ 17.6%）
- Ca²⁺ meq = 78.0 / 40.078 × 2 = 3.891 meq/L（%ep ≈ 67.8%）
- Mg²⁺ meq = 35.0 / 24.305 × 2 = 2.881 meq/L（%ep ≈ 25.1%）
- Na⁺ meq = 18.0 / 22.990 × 1 = 0.783 meq/L（%ep ≈ 7.1%）
- 阴离子优势：HCO₃（>25%）
- 阳离子优势：Ca（>25%）、Mg（≈25%，刚好超过阈值）
- **水化学类型：HCO₃-Ca·Mg**
- **分区号：4**（行1列4）

## 6 水质类别与用途

根据 GB/T 14848-2017，地下水质量分为五个类别：

| 类别 | 名称 | 色标 | 适用用途 |
|------|------|------|---------|
| I 类 | 优良 | 绿色 | 地下水化学组分含量最低，适用于各种用途 |
| II 类 | 良好 | 浅绿 | 地下水化学组分含量较低，适用于各种用途 |
| III 类 | 较好 | 黄色 | 以人体健康基准值为依据，主要适用于集中式生活饮用水水源及工农业用水 |
| IV 类 | 较差 | 橙色 | 以农业和工业用水质量要求为依据，适用于农业和部分工业用水，适当处理后可作生活饮用水 |
| V 类 | 极差 | 红色 | 不宜作为生活饮用水水源，其他用水可根据使用目的选用 |

> 在环评报告中，通常以 III 类标准作为地下水质量达标与否的判据。IV 类和 V 类属于超标，需分析超标原因并评估对环境敏感目标的影响。

## 7 注意事项

1. **评价因子的选择**：计算器内置了 GB/T 14848-2017 全部可数值化的 16 个评价因子，使用者可根据实际监测项目填写，未填写的因子自动跳过
2. **数据单位**：监测值必须与标准限值的单位一致。计算器表格中已标注各因子的标准单位（mg/L、NTU 等），输入时请注意
3. **pH 输入**：pH 为无量纲值，直接输入小数即可（如 7.2），不需要单位
4. **未检出格式**：支持多种"未检出"文本格式（见 2.3 节），系统自动提取检出限数值并以 50% 参与计算
5. **综合评定方法**：采用单因子评价法（最差类别），这是环评行业通行做法，与多因子综合评价法（加权平均等）不同
6. **苏卡列夫分类的局限**：仅考虑 6 种主要离子，对于含特殊成分（如高砷、高氟）的地下水，需结合其他分类方法综合判断
7. **苏卡列夫分区号的用途**：分区号可用于编制水化学类型分布图，将采样点按分区号标注在地图上，直观展示地下水化学成分的空间分带规律

## 8 常见问题 (FAQ)

### Q1 为什么综合评定类别比我想象的差？

这是单因子评价法（又称"一票否决法"）的特点：综合评定取所有参评因子的**最差类别**。例如 15 个因子全部为 I 类，只要铬(Cr⁶⁺)达到了 IV 类，综合评定就是 IV 类。这是 GB/T 14848-2017 推荐的评价方法，也是环评行业通行做法。

如果需要了解整体水质"平均水平"，可以参考标准指数明细表中的 Pi 值——Pi 值越小表明该因子偏离标准程度越小。但报告中仍应以单因子法评定结果为准。

### Q2 输入了监测值但结果显示"无法计算"？

可能的原因：
- 监测值包含无法解析的非数字、非"未检出"文本（如"定性描述"等文字）
- 数值格式不规范，如带有中文逗号"1,234"或单位"250mg/L"（计算器要求只输入纯数字）

**解决方法**：确保监测值输入框中只填写数字（如 `250`）或标准格式的"未检出"文本（如 `未检出0.01`），不要附加单位。

### Q3 未检出数据应该怎么填写？

在监测值列直接输入包含"未检出"字样的文本即可，计算器会自动识别并提取检出限数值。推荐格式：

- `未检出0.01` — 最常用格式，检出限为 0.01
- `未检出 <0.05` — 带小于号，检出限为 0.05
- `未检出(0.02)` — 带括号，检出限为 0.02

处理规则：以检出限的 50% 参与计算（如检出限 0.01，则以 0.005 计算 Pi），通常 Pi 极小，自动评定为 I 类。结果表中会保留原始"未检出"显示，便于核对。

### Q4 Pi 值和评定类别是什么关系？

Pi（标准指数）和类别是两套独立的判定逻辑：
- **Pi 值**：以 III 类标准限值为分母计算的比值，反映监测值偏离 III 类标准的程度。Pi ≤ 1.0 表示达标（≤III 类），Pi > 1.0 表示超标（>III 类）
- **类别**：通过将监测值与 I~V 类各级限值逐一比对确定，精度高于 Pi 的简单二值判断

两者可能出现"Pi ≤ 1 但类别为 IV 类"的情况吗？不会。Pi ≤ 1 等价于类别 ≤ III 类。但如果 Pi 略大于 1（如 1.02），类别可能是 III 类或 IV 类——取决于 IV 类限值的具体位置。

### Q5 为什么感官性状指标（嗅和味、肉眼可见物）不在评价因子列表中？

"嗅和味"和"肉眼可见物"的 GB/T 14848-2017 标准限值为文本型（"无"或"有"），无法进行数值化的标准指数计算，因此计算器自动排除了这两项。"色(度)"和"浑浊度"有数值型限值（如"≤15 度"、"≤3 NTU"），已保留在列表中。

环评报告中，感官性状指标通常以文字描述方式评价，不纳入标准指数法计算。

### Q6 一个水样中有些因子没有监测数据怎么办？

直接留空即可。未填写的因子自动跳过，不影响其他因子的计算和综合评定。这是正常情况——实际监测中很少会对全部 39 项指标都进行检测，一般只检测 20 余项常规指标。

### Q7 多个水样可以一起评价吗？

可以。点击"添加水样"按钮可新增任意数量的水样卡片，每个水样独立填写监测值。点击"计算评价"后，所有水样同时计算，结果以卡片形式并排展示，便于对比不同采样点的水质差异。

典型应用场景：同一含水层的多个监测井对比评价、丰水期/枯水期对比评价、不同深度含水层水质对比。

### Q8 苏卡列夫分类中某个离子的 %ep 刚好等于 25%，算不算优势离子？

计算器采用严格大于 25% 的判定（>25%ep），等于 25% 的情况不计入优势离子。这是苏卡列夫分类法的常规阈值处理方式。实际数据中 %ep 刚好整 25% 的情况极为罕见，通常不影响分类结果。

### Q9 苏卡列夫分类结果为"未知-未知"是怎么回事？

当 6 种离子浓度全部输入为 0 或未填写时，所有离子的 %ep 均为 0，没有任何离子超过 25%ep 阈值，因此无法确定水化学类型。

**解决方法**：检查离子浓度数据是否已正确填写。注意输入值为质量浓度（mg/L），不要填入毫当量浓度或其他单位的数值。

### Q10 标准指数法和综合评价法有什么区别？

| 对比项 | 单因子标准指数法（本工具采用） | 综合评价法（加权法） |
|--------|--------------------------|------------------|
| 方法 | 取各因子最差类别 | 计算各因子 Pi 的加权平均值 |
| 特点 | 一票否决，偏保守 | 反映整体平均水平 |
| 适用 | 环评报告、水质达标判定 | 水质趋势分析、区域对比 |
| 标准 | GB/T 14848-2017 推荐 | 非国标方法，学术界使用 |

环评行业普遍采用单因子标准指数法。如果要表达"整体污染程度"的量化概念，可以在报告中同时列出超标因子数、最大 Pi 值等辅助信息。

### Q11 总硬度的单位为什么写的是 CaCO₃？

这是水质分析中的惯例表示方法。总硬度以碳酸钙（CaCO₃）当量表示，单位 mg/L 等价于 ppm。如果你的监测报告以德国度(°dH)或 mmol/L 为单位，需要先换算：

- 1 mmol/L = 100.09 mg/L (CaCO₃)
- 1 °dH = 17.848 mg/L (CaCO₃)

### Q12 为什么锰的 III 类标准限值是 0.10，但输入 0.08 却评为 IV 类？

请检查输入的数值和单位是否与标准一致。锰的标准限值为 0.10 mg/L，输入 0.08 mg/L 时 Pi = 0.08/0.10 = 0.80，应评为 III 类，不会出现 IV 类的情况。

如果确实遇到了评定类别与预期不符的情况，请检查：
- 监测值是否误输入了其他因子的数值
- 监测值的单位是否与标准一致（如误将 μg/L 填入 mg/L 的字段）
